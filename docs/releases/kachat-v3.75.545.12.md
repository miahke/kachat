## Изменения

- Исправлена отправка первого сообщения при создании группы. Если создать группу не удалось, сообщение больше не отправляется в ранее открытый чат.
- Улучшена обработка смены аккаунта и ошибок при создании группы: введённый текст сохраняется в окне, а повторное создание уже начатой группы блокируется.

Приложение подписано тем же локальным тестовым сертификатом, что предыдущий выпуск. Проверка на физическом устройстве и обмен с Nym для этой версии не проводились.
