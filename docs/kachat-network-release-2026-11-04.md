# kachat test.2 — сетевой патч, 2026-11-04

Добавлены встроенные Arti, obfs4, WebTunnel и Snowflake для трёх ABI, реальный процент загрузки Tor, выбор протокола и вставка пользовательских мостов. Snowflake использует встроенную публичную конфигурацию, если строка не задана. Секреты мостов исключены из журнала.

Выбранный Tor/qWDTT сохраняется до запуска ядра. Остановка, ошибка, перезапуск процесса и отмена капчи не включают прямой маршрут. Смена соединения закрывает прежние сокеты; устаревшие результаты игнорируются. Состояние готовности локального прокси отделено от доступности сервиса и доставки сообщений. Проверка HTTPS выполняется через выбранный прокси с обычной проверкой сертификата.

Перенесены применимые настройки qWDTT, полный импорт/экспорт профиля, фиксированы два транспортных worker. WG и аутентифицированный Raw v2 сохранены. Системные VPN/TUN-настройки исключены, поскольку приложение использует локальный SOCKS. Значение `port` в подписке теперь правильно трактуется как локальный SOCKS-порт; адрес удалённого узла задаётся через `peer`. Несколько хэшей импортируются отдельными профилями. Подробная таблица: [qWDTT parity](qwdtt-settings-parity.md).

VK предлагает пользователю решить изображение или официальную интерактивную капчу во всплывающем окне. Разрешены только точные официальные HTTPS-домены; нет обхода TLS, доступа WebView к файлам, автоматического решателя и JS-интерфейса к Android. Ответы связаны с текущим запросом и ограничены временем. Отмена, выход и закрытие Activity завершают ожидающий запрос. Повторное нажатие генерации хэша объединяется с текущим запросом. Новые ядра qWDTT пересобраны для всех ABI.

Русская локализация предыдущего патча включена. Исходные форматы идентичностей, шифрование сообщений и атрибуция NYM сохранены. Приложение по-прежнему использует серверные API NYM; деплоер устанавливает только qWDTT, а не сервер мессенджера.

## Проверки и ограничения

- Flutter analyze без замечаний; 43 теста пройдены, один необязательный предпросмотр пропущен.
- Android/JVM: 50 тестов, без ошибок. Go: проверки native/qwdtt, включая ручную image/smart captcha.
- Изолированный Android 10 x86_64: настоящие нативные Tor/Snowflake подключились; SOCKS потребовал аутентификацию, передал домен удалённо и успешно выполнил HTTPS с проверкой сертификата. Два instrumentation-теста для каждого режима пройдены.
- Пользовательские obfs4/WebTunnel проверены парсером и сборкой настоящих ядер; живой сеанс с собственными мостами в этом выпуске не подтверждён.
- Реальный VK-аккаунт, прохождение живой капчи, текущий пользовательский VPS и физический Pixel/GrapheneOS в этой проверке не использовались. Синтетические тесты не подтверждают доступность любого TURN/VPS или обход конкретного белого списка.
- WebRTC/P2P заблокированы при защищённом маршруте, чтобы не обходить прокси; голосовые заметки и файлы сохраняются. Внешние приложения и служебный bootstrap используют свои соединения. Это прокси приложения, не системный VPN.
- Ограничения фоновых служб Android сохраняются; при остановке службы защищённый маршрут остаётся закрытым. Физические проверки батареи и Android 17 остаются отдельным этапом.
- Это тестовый Release/AOT выпуск с прежним локальным тестовым сертификатом. Нового аудита Astra и сертификации безопасности этого патча не проводилось.

Проверки подписи, ABI, выравнивания, native checksums и состава конкретных APK записаны в `verification.txt` рядом с артефактами релиза. Ключи подписи и карты обфускации не публикуются.
