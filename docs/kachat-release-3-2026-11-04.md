# kachat release 3 — 2026-11-04

## Изменения

- Подписка qWDTT со списком хэшей импортируется одним профилем. Ползунок числа транспортных каналов: от 1 до 27 на доступный хэш, максимум 108; значение сохраняется и экспортируется. Старые профили без этого поля сохраняют прежние два канала. Карточки #1–#4 из старого импорта не являются четырьмя одновременно работающими потоками: активен один выбранный профиль. Они не удаляются автоматически; для объединённой карточки импортируйте исходную подписку заново и удалите ненужные старые карточки.
- Tor: открыт выбор обычных мостов с RSA fingerprint; улучшены распознавание вставленного формата и проверка строк обычного Tor, obfs4, WebTunnel, Snowflake, префикса Bridge, IPv6 и пробелов/табуляций. Парсер не подменяет отсутствующее нативное ядро; неизвестные транспорты отклоняются.
- Внешние SOCKS5, HTTP CONNECT и HTTPS CONNECT. Импорт URI, адреса host:port, host:port:user:password, user:password@host:port, IPv6, Base64-реквизитов/URI и Telegram SOCKS-ссылок. Импорт не скачивает ссылки. MTProto Telegram и Shadowsocks не являются SOCKS5 и диагностируются как неподдерживаемые. Обычный HTTP не шифрует реквизиты до прокси; HTTPS CONNECT проверяет TLS-сертификат прокси. HTTPS приложения проверяется независимо.
- Настройки прокси сохраняются в существующем Android secret store; выбранный маршрут восстанавливается без прямого fallback. Проверка доступности — отдельный HTTPS-запрос. Готовая конфигурация не объявляется доказательством доставки сообщения.
- Локальный архив личных чатов, групп и каналов, действия «В архив»/«Вернуть из архива», скрытие и открытие архива через меню. Данные разделены по аккаунтам; архив не удаляет сообщения и не покидает канал.
- Возвращены реальные исходные функции магазина, Lightning и кредитов Nymbot в самом конце информации (i). Вход и действия требуют предупреждения о проверке получателя/суммы/счёта и необратимости; чатовые действия направляют к информации. LNURL использует тот же маршрутизируемый API-клиент. Никакие реальные платежи при проверках не выполнялись.

Исходные протоколы NYM и атрибуция сохранены. Приложение использует серверные API NYM; qWDTT-деплоер не заменяет backend мессенджера. Публичный выпуск под AGPL-3.0 сохраняет лицензии компонентов и исходники. Подпись остаётся прежней для обновления существующего APK.

## Проверки

Flutter analyze: замечаний нет. Flutter: 63 теста пройдены, один необязательный предпросмотр пропущен. Android/JVM: 57 тестов, ошибок нет. Go-тесты qWDTT пройдены. Проверки конкретных APK записываются в verification.txt релиза. Проверяются Flutter analyze, Flutter tests, JVM tests, Go tests, нативные хэши и ABI, выравнивание APK/ELF, сертификат обновления и отсутствие переданных личных реквизитов/путей в исходниках и APK. Модульные тесты включают импорт, worker count, маршрутизацию SOCKS/HTTP, удалённое имя назначения, отказ прокси без прямого выхода, archive persistence и платёжные подтверждения.

Не выполнялись реальные платежи, вход в пользовательский VK, деплой на VPS или установка на физический Pixel. Новых живых тестов пользовательских мостов/белого списка в этом патче не было. Успешные Tor/Snowflake HTTPS-проверки предыдущего сетевого патча описаны отдельно; они не гарантируют доступность каждого моста/провайдера. Android 17/GrapheneOS, фоновые ограничения и батарея требуют проверки на устройстве. Обычный GitHub Release не является независимым аудитом безопасности.
